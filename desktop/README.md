# Desktop front end

React/TypeScript UI (Turkish labels) and the Tauri 2 shell of Notes, an
unofficial client compatible with Samsung Notes. The UI talks only to the
local engine's loopback HTTP API (contract: `../docs/APP_CONTRACT.md`); the
production bundle contains no sample data or mock API.

## Build

```sh
npm ci
npm run build
cargo build -p notes-engine                      # from the repository root
cargo build --manifest-path src-tauri/Cargo.toml
```

The development binary (`src-tauri/target/debug/linux-notes-desktop`) is bound
to the source checkout: it starts the pure Rust `notes-engine` binary as a
child process (or in-process with the `embedded-engine` feature) and the
engine serves `desktop/dist`. `LINUX_NOTES_PROJECT_ROOT` selects another
checkout. GTK3 / WebKitGTK 4.1 system libraries are required on Linux.

The shell manages only its own child: it waits for a 0600 runtime file in a
private 0700 temporary directory, checks the PID, loopback origin, port and
token, never navigates the window to external origins, and stops its engine
on exit (Linux parent-death signal covers an unexpected launcher exit).

For an isolated offline session use `LINUX_NOTES_DATA_DIR=/new/private/dir`
and `LINUX_NOTES_OFFLINE=1`; the normal library is not touched.

## Behaviour notes

- Shortcuts are configurable in Settings and stored in the local SQLite
  library. Folder and note-card actions are on the right-click menu
  (Shift+F10 / Menu key also work); a normal left click opens a note.
- Saving locally and Cloud confirmation are separate states; "Save" never
  claims Cloud success. Cloud writes are verified by a full readback.
- The local access token is moved from the URL fragment to sessionStorage and
  sent only to same-origin `/api/` requests. Samsung tokens never reach the UI.
  No remote fonts, analytics or CDNs.

## Icons and fonts

`public/windows-assets/*.svg` are free Lucide icons (ISC), generated by
`assets-free/generate.mjs`; see `assets-free/README.md` for the mapping and
`assets-free/LICENSE`. The app icon source is `assets-free/app-icon/notes-icon.svg`.
No fonts are bundled: the UI uses a system font stack (Noto Sans, Cantarell,
Ubuntu, DejaVu Sans, system-ui). If a font the user owns is placed in the
engine's optional local font directory, it is served through the fixed
`/local-fonts/` allowlist; nothing is downloaded.

## Tests

```sh
npm run build
npx tsc --noEmit
npx playwright test          # NOTES_TEST_OUTDIR=dist-test to test a separate build
npm run test:integration     # isolated offline engine round
```

Tests use synthetic fixtures only and never call a real account. Playwright
uses `PLAYWRIGHT_CHROMIUM_PATH`, else `/usr/bin/chromium` if present, else its
bundled Chromium.
